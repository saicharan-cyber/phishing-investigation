# 📧 Phishing Investigation Case Study

## 🎯 Objective
Investigate suspected phishing email and determine impact.

---

## 🔎 Investigation Process

1. Email header analysis
2. Extract sender IP
3. Verify SPF/DKIM
4. Check domain reputation
5. Analyze attachment hash

---

## 🛠 Tools Used
- VirusTotal
- Email Header Analyzer
- Splunk SIEM

---

## 🚨 Indicators Identified
- Suspicious sender domain
- Malicious attachment hash
- External IP reputation flagged

---

## 🎯 MITRE ATT&CK Mapping
T1566 – Phishing

---

## 📌 SOC Action Taken
- Blocked malicious domain
- Reset affected user credentials
- Notified stakeholders
